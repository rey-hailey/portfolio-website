# Architecture Decision Records (ADR)

확정된 기술 결정을 바꾸거나 스펙에 없는 라이브러리/서비스를 추가할 때는 ADR을 먼저 작성하고 승인받는다.

- 파일명: `NNNN-<주제>.md` (0001부터 순번)
- 상태: Proposed / Accepted / Superseded by NNNN / Rejected
- 형식: 맥락 → 결정 → 대안 → 결과(트레이드오프)
