## 2. Retina 측정

- 뷰포트: 375px, 1440px
- `deviceScaleFactor`: 2
- 대상: 6페이지의 표시 중인 모든 raster `<img>`
- 표시 폭: `getBoundingClientRect().width`
- 실제 리소스 폭: `currentSrc`에 대응하는 `dist/_astro/*` 파일의 `sips pixelWidth`
- 기준: 실제 리소스 폭 / 표시 폭 ≥ 1.8
