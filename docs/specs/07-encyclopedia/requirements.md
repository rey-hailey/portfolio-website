## 1. 배경 / 목표

검색으로 들어온 동료가 용어 정의를 바로 읽고 관련 용어로 이동하게 한다(S3, G3·G4). 이 스펙은 목록·상세 화면과 검색·필터·관련 용어 로직을 만든다. 용어 원고는 사이트 주인이 쓴다(PRD 10.1).

## 2. 사용자 스토리

- US-01: 동료로서 나는 용어를 검색·카테고리·초성으로 찾고 싶다.
- US-02: 동료로서 나는 첫 문단에서 정의를 바로 읽고, 관련 용어로 이어 읽고 싶다.

## 3. 요구사항

### ENC-R01: 초성 계산
- P0 · THE SYSTEM SHALL 용어명 첫 글자에서 초성(ㄱ~ㅎ, 쌍자음은 기본 자음) 또는 영문 대문자를 계산한다.
- AC1: 단위 테스트: 컨텍스트→ㅋ, 까다로움→ㄱ, 쌍둥이→ㅅ, RAG→R, llm→L, 3D→#.

### ENC-R02: 검색·카테고리·초성 필터
- P0 · WHEN 사용자가 검색어·카테고리·초성을 고르면, THE SYSTEM SHALL 용어명·영문명·동의어·정의에서 공백·대소문자를 무시하고 찾은 결과만 보여 주고, 상태를 URL(`?q=&category=&initial=&page=`)에 남기며 결과 수를 `aria-live`로 알린다. JS가 없으면 전체 목록이 보인다.
- AC1: 필터 유틸 단위 테스트(검색어 한글·영문·동의어·정의, 카테고리, 초성 ㄱ에 ㄲ 포함, 조합). AC2: 브라우저 QA(샘플 임시 공개).

### ENC-R03: 페이지네이션과 상태 표시
- P0 · THE SYSTEM SHALL 필터 결과를 12개씩 나누고 "N개 용어 · p/T페이지"를 표시한다 (PRD 5.6 문구).
- AC1: paginate 단위 테스트(0개→1/1, 13개→2페이지, 범위 밖 page는 마지막으로). AC2: 상태 문구 포맷 단위 테스트.

### ENC-R04: 목록 카드
- P0 · THE SYSTEM SHALL 카드에 용어명, 영문명, 정의(1~2문장)를 보여 주고 상세로 링크한다. 공개 용어가 없으면 빈 상태(`[TODO: 문구]`)를 보여 준다.
- AC1: 컨테이너 테스트(카드 필드·data 속성). AC2: Playwright 빈 상태.

### ENC-R05: 상세 구조
- P0 · THE SYSTEM SHALL `/encyclopedia/<slug>`에 브레드크럼(`nav[aria-label]` > ol), H1 용어명(+영문명), 마지막 업데이트 날짜(`<time>`), 첫 문단 정의, 목차(H2 링크, 모바일은 `<details>` 접기), 본문, FAQ(`<details>` 아코디언), 참고 문서, 관련 용어, 다른 용어를 보여 준다.
- AC1: 브라우저 QA(샘플 임시 공개)로 각 요소 존재 확인. AC2: 목차 유틸 단위 테스트(H2만, slug 일치).

### ENC-R06: "기획자에게 왜 중요한가" 고정 섹션
- P0 · IF 공개 용어 본문에 `## 기획자에게 왜 중요한가`가 없으면, THEN THE SYSTEM SHALL 테스트를 실패시킨다.
- AC1: 저장소 전수 단위 테스트.

### ENC-R07: 관련 용어 (수동 + 자동 역링크)
- P0 · THE SYSTEM SHALL 관련 용어 = 수동 지정(relatedTerms) ∪ 나를 지정한 용어(역링크), 자기 자신·비공개 제외, 수동 지정 먼저 순서로 계산한다. "다른 용어"는 관련 용어를 뺀 나머지에서 최대 6개(용어명 가나다순 다음 항목부터 순환)다.
- AC1: 단위 테스트(역링크, 중복 제거, 비공개 제외, 다른 용어 순환).

### ENC-R08: 품질
- P0 · 01 품질 기준(반응형, 제목 순서, Lighthouse 95+, JS 예산). 필터 스크립트는 공개 용어가 있을 때만 싣는다.
- AC1: 반응형 /encyclopedia, 제목 순서, Lighthouse ≥ 0.95.

## 4. 범위 밖

- 공유 버튼(P1), `encyclopedia-term` 스킬(P1), DefinedTerm·FAQPage·BreadcrumbList JSON-LD(09), 용어 원고(사이트 주인), 검색 사용 GA4 이벤트(10)

## 5. 사이트 주인 검토 대기

1. D6 결정: 검색 라이브러리(Pagefind·Fuse.js)를 쓰지 않고 빌드 때 카드에 넣은 데이터로 직접 거른다. 용어 20~30개 규모에서 의존성·추가 요청이 0이다. 용어가 수백 개로 늘면 Pagefind를 다시 검토한다.
2. 용어 원고(첫 후보 24개, PRD 10.2)를 써 주시거나 초안 작성을 지시해 주세요. 지금은 빈 상태로 보인다.
